# 行列 12 輸入法轉換器 (Array 12 Input Method Converter)

本專案旨在將傳統的**行列 30 輸入法**（使用 30 個按鍵）簡化並轉換為**行列 12 輸入法**。這非常適合用於數字小鍵盤、手持裝置、遙控器或虛擬小鍵盤等輸入場景。

本專案提供兩種鍵位映射版本：
1. **標準版**：僅使用 12 個按鍵（`0-9`、`↑` / `/`、`↓` / `*`），適合一般鍵盤或模擬器。
2. **LIME 版**：僅使用 12 個按鍵（`0-9`、`↑` / `,`、`↓` / `.`），專為 LIME 輸入法設計，可避免符號衝突並便於行動裝置輸入。

專案中提供了對應的 Python 轉換腳本，能將現有的行列 30 `.cin` 格式對照表，自動轉換為行列 12 的 `.cin` 格式對照表。

## ⌨️ 行列 12 鍵位映射原理

行列 12 輸入法的核心思想是保留行列輸入法的「第一碼、最後碼」與「字根碼（前三後一）」邏輯，但將原本分佈於英文鍵盤三橫列的 30 個按鍵，對應到 10 個數字鍵加上「上（↑）」與「下（↓）」兩個輔助鍵：

*   **中排鍵 (基本鍵)**：直接對應數字鍵 `1` 到 `0`。
*   **上排鍵**：對應數字鍵加上 **上 (`↑`)**，在標準版使用 `/`，在 LIME 版使用 `,`。
*   **下排鍵**：對應數字鍵加上 **下 (`↓`)**，在標準版使用 `*`，在 LIME 版使用 `.`。

## 🛠️ 轉換腳本功能

專案內包含兩個轉換腳本：
*   [convert_ar30_to_ar12.py](convert_ar30_to_ar12.py)：標準版轉換腳本。
*   [convert_ar30_to_ar12_lime.py](convert_ar30_to_ar12_lime.py)：LIME 版轉換腳本。

轉換腳本執行以下轉換邏輯：

1.  **自動修改檔案標頭**：
    *   **標準版**：將 `%ename array30` 改為 `%ename array12`，`%cname 行列30` 改為 `%cname 行列12`。
    *   **LIME 版**：將 `%ename array30` 改為 `%ename array12lime`，`%cname 行列30` 改為 `%cname 行列12LIME`。
2.  **重定義按鍵名稱**：
    *   **標準版**：將 `%keyname` 區間內的按鍵重設為 `1-0`、`/` (↑)、`*` (↓)。
    *   **LIME 版**：將 `%keyname` 區間內的按鍵重設為 `1-0`、`,` (↑)、`.` (↓)。
3.  **移除不相容設定**：
    *   移除過往行列 30 常見的快碼定義 `%quick`。
    *   清理如 `%endkey 1234567890`、`%space_style 2` 等多餘配置。
4.  **轉換字詞對照表**：
    *   將 `%chardef` 區間中所有字詞的行列30按鍵組合，依據上述鍵位對照表轉換成 12 鍵組合。
    *   過濾掉原本單個數字 `1` 到 `0` 的基本鍵對應，避免按鍵重疊衝突。

## 🚀 使用方法

請確保你的系統已安裝 Python 3。

### 1. 標準版轉換

```bash
python convert_ar30_to_ar12.py <輸入的行列30_cin檔案> <輸出的行列12_cin檔案>
```

**範例**：
* 轉換標準字表：
  ```bash
  python convert_ar30_to_ar12.py ar30-regular-v2026-1.0-20260329.cin ar12-regular-v2026-1.0-20260329.cin
  ```
* 轉換大字表：
  ```bash
  python convert_ar30_to_ar12.py ar30-big-v2026-1.02-20260407.cin ar12-big-v2026-1.02-20260407.cin
  ```

### 2. LIME 版轉換

```bash
python convert_ar30_to_ar12_lime.py <輸入的行列30_cin檔案> <輸出的行列12_lime_cin檔案>
```

**範例**：
* 轉換 LIME 標準字表：
  ```bash
  python convert_ar30_to_ar12_lime.py ar30-regular-v2026-1.0-20260329.cin ar12-lime-regular-v2026-1.0-20260329.cin
  ```
* 轉換 LIME 大字表：
  ```bash
  python convert_ar30_to_ar12_lime.py ar30-big-v2026-1.02-20260407.cin ar12-lime-big-v2026-1.02-20260407.cin
  ```
